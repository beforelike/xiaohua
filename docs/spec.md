# 产品需求规格

## 1. 背景

传统 AI 生图通常一次生成整张图片，局部修改困难且成本高。笑画将每个主要元素作为独立图层，让用户像指挥绘画助手一样，通过语音逐步创建和编辑作品。

## 2. 目标

- 用户不依赖鼠标和键盘即可完成一次完整创作。
- 新增复杂对象时生成独立素材，普通位置和尺寸修改不重复调用生成 API。
- 系统始终展示当前监听、识别、理解、生成、成功或失败状态。
- 保存结果同时包含合成图片和可继续编辑的项目 JSON。

## 3. 非目标

- P1 不做人物局部选择与语义分割。
- P1 不做多人协作、账号系统、云端图库和跨设备同步。
- P1 不承诺浏览器之外的桌面或移动原生应用。
- P1 不追求专业设计软件级别的路径、蒙版和混合模式。

## 4. 核心用户流程

1. 用户打开应用并授权麦克风。
2. 用户说“创建一张童话风格的画”。
3. 用户依次添加草地、树和太阳。
4. 用户说“把太阳变小一点并移到右上角”。
5. 用户说“选择树，把它换成更梦幻的风格”。
6. 用户说“保存作品”。
7. 系统下载 PNG 和项目 JSON，并反馈结果。

## 5. P1 用户故事与验收标准

### US-01 语音输入

作为用户，我可以点击一次开始按钮后连续使用自然语言控制应用。

- 明确展示等待授权、监听中、识别中和错误状态。
- 浏览器不支持或拒绝权限时，提供可理解的降级说明。
- 识别文本在执行前可见。

### US-02 创建对象

作为用户，我可以说“在右上角画一个太阳”创建独立元素。

- 成功后新增且选中一个图层。
- 图层保存名称、提示词、素材来源、位置、尺寸和时间。
- 生成失败不修改已有图层，并触发降级或错误反馈。

### US-03 管理图层

作为用户，我可以选择、删除和调整对象层级。

- 支持按名称、当前选中对象和最近创建对象定位。
- 重名对象产生歧义时不得随机执行。
- 删除后选择状态落到合理的相邻图层或空状态。

### US-04 修改对象

作为用户，我可以移动、缩放、旋转和重命名单个对象。

- 属性修改不调用图片生成 API。
- “变大一点”等相对操作使用一致、可测试的步进值。
- 超出画布时进行边界约束或明确允许部分出界。

### US-05 重新生成对象

作为用户，我可以只改变某个对象的内容或风格。

- 只替换目标图层素材，保留其位置、尺寸和层级。
- 新素材成功前保留旧素材。
- 记录新旧提示词和生成状态。

### US-06 保存作品

作为用户，我可以通过语音导出作品。

- 输出 PNG，视觉结果与画布一致。
- 输出符合当前 Schema 版本的 JSON。
- 导出失败时保留项目并提供重试提示。

### US-07 状态反馈

作为用户，我能持续知道系统正在做什么。

- 状态至少包含 `idle`、`listening`、`recognizing`、`parsing`、`generating`、`success`、`error`。
- 状态包含中文说明，不能只用颜色或动画表达。

## 6. P2

- 全局风格与对象局部重新生成
- 预设素材、文字贴纸和基础图形
- 复制、组合、撤销与重做
- 颜色、透明度和精细旋转调整

## 7. P3

- 图像语义分割和人物局部替换
- 复杂遮挡关系与蒙版编辑
- 高清多图层批量重绘

## 8. 非功能需求

- 首屏在常见桌面网络环境下可交互时间目标小于 3 秒，不包含模型生成。
- 普通本地图层操作目标响应小于 100 毫秒。
- 生成请求默认 45 秒超时，最多自动重试一次。
- 项目 JSON 必须可版本迁移，未知字段应被安全忽略。
- 支持最新版 Chrome 和 Edge；Safari/Firefox 的语音能力允许降级。

## 9. 成功指标

- 演示脚本从开始到导出无手动编辑即可完成。
- P1 命令测试集解析准确率达到 90% 以上。
- 本地对象操作不触发图片生成请求。
- 任一外部 API 失败后作品状态仍可继续操作和导出。
