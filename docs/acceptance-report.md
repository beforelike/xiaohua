## 2026-06-14 动作语义、身份保持与记忆事务复测

- 实机短提示词“画一个月光森林里的小狐狸故事”由 LLM 正确扩展为月光森林背景和小狐狸两个图层，画面风格、冷暖色关系与空间构图一致，未发现残留线稿。
- 实机重绘“让小狐狸低头看地上的月光，保持它的外形和颜色不变”暴露身份漂移：候选图从橙色坐姿狐狸变为棕色站姿狐狸。OpenCV 颜色直方图距离为 `0.501`，身份色漂阈值从 `0.60` 收紧到 `0.45` 后该样本会被拒绝。
- 参考图重绘提示词明确区分不可变身份与可变动作：保持物种、脸部、体型、标记和颜色，同时禁止沿用旧姿态和旧头部方向。
- 透明动作素材新增 Gemini Flash 像素语义审计，检查单主体、对象类型、动作可见性和参考身份；审计失败会重试并降级，审计服务不可用时仍保留 OpenCV/rembg 确定性门禁。
- 实机动作请求期间 `gemini-3-pro-image` 网关连续返回 `502`；WebUI 兜底候选被视觉审计判定为 `SEMANTIC_ACTION_MISMATCH`，系统拒绝错误素材并保留作品。外部主生图服务当前仍不稳定，不能据此宣称动作生图已稳定通过。
- 作品记忆改为成功事务：只有命令实际完成后才写入近期意图；失败生成和取消确认不会污染场景摘要。已有图层时优先根据真实画布重新归纳主体、色彩和光线，不再用模型计划覆盖实际画面。
- 自动化：`154` 个 Vitest 测试、`8` 个 Playwright 流程、lint、typecheck 和 build 全部通过。
