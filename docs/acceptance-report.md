## 2026-06-13 对象修改实机回归

- 环境：Windows，桌面 Chromium 浏览器，`http://127.0.0.1:5173`。
- 配置：规则指令解析、Mock 图片生成、Mock ASR、关闭 LLM 提示词增强。
- 步骤一：点击树素材，记录图层 ID；输入“把树画成一棵秋天的树”并执行。
- 结果一：页面提示“已重新生成树”，图层数量保持为 1，修改前后图层 ID 均为 `60a93138-ff39-485a-8b88-4049378d4c7c`。
- 步骤二：输入“在树旁边画一只小鸟”并执行。
- 结果二：页面提示“新素材已经加入画布”，图层数量变为 2，树与小鸟使用两个不同图层 ID。
- 结论：已有对象修改不会再创建新对象或新图层，明确新增对象仍正常创建独立图层。

## 2026-06-13 真实模型全链路实机测试

- 环境：Windows，桌面 Chromium 浏览器，项目 Web `5173`、项目 API `8787`、Stable Diffusion WebUI `7860`。
- 配置：远程 LLM 指令解析与提示词增强、本地 Stable Diffusion WebUI、Mock ASR。
- 通过：三个服务健康检查均返回 `200`。
- 通过：预设树执行“把树画成一棵秋天的红叶树”后使用真实模型重新生成，图层数量保持为 1，图层 ID 保持不变。
- 通过：执行“画一片草地”后新增独立背景图层。
- 通过：执行“把树移到右边”和“删除草地背景”后，页面状态与图层列表正确更新。
- 通过：保存作品时成功生成 PNG 与项目 JSON Blob，页面显示导出成功；内置测试浏览器取消了实际下载落盘，控制台无应用错误。
- 失败：执行“画一只小猫”时，系统额外创建用户未要求的“自然草地背景”图层。
- 失败：生成的“小猫”素材视觉内容不是猫，而是金属圆盘状物体；当前透明背景和素材校验未识别该语义错误。
- 性能：简单角色创建需依次完成 LLM 拆分、身份锚点、三视图和动作素材，实测约 100 秒，期间缺少总体进度与剩余时间提示。
- 未覆盖：真实麦克风与本地 ASR 语音输入。
- 结论：基础服务与对象编辑链路可用，但完整角色创建存在语义拆分和生成质量问题，本轮全链路验收不通过。
