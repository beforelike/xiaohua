# 纯语音绘图能力设计记录

更新时间：2026-06-13

## 目标

用户除首次浏览器麦克风授权外，不使用鼠标或键盘完成创建、编辑、确认、消歧和保存作品。实现优先级依次为：

1. 语音指令闭环与容错。
2. 语音到画布反馈的响应延迟。
3. 复杂指令拆解与可靠执行。

## 计划支持的指令能力

| 类别 | 示例 | 计划 |
| --- | --- | --- |
| 创建 | “画一个太阳”“画一匹马在草原上奔跑” | P1 |
| 选择与指代 | “选择树”“把它变小”“删除刚才那个” | P1 |
| 对象编辑 | 移动、缩放、旋转、重命名、重新生成 | P1 |
| 图层管理 | 删除、调整层级 | P1 |
| 保存 | “保存作品”“导出作品” | P1 |
| 对话控制 | “确认”“取消”“第一个”“右边那个” | P1 |
| 故障恢复 | “重试”“撤销刚才的操作” | P2 |
| 复杂指令 | “先选择树，然后缩小并移到右边” | P2 |

## 当前分支实现

分支：`codex/feat-voice-command-loop`

- 浏览器语音能力可用时自动尝试启动，不依赖应用内点击。
- 浏览器语音识别保持连续监听，会话意外结束时自动恢复。
- 最终转写文本直接进入原有结构化命令解析和执行链。
- 低置信度命令支持语音“确认”或“取消”。
- 重名对象支持“第一个”“第二个”“左边那个”“右边那个”消歧。
- 文本输入、按钮确认和素材点击继续保留为调试及降级路径。
- 自动化测试覆盖自动执行、确认、取消、空间消歧和监听恢复。

## 容错设计

- 普通语音仍经过服务端规则或 LLM 解析以及 Schema 校验，不直接修改画布。
- 低于置信度阈值的命令保持待确认状态，不猜测执行。
- 重名目标禁止随机选择，必须通过序号、空间提示或界面选择明确目标。
- 无法识别待确认回答时不退出对话，提示可说的控制词。
- 指令服务或生成服务失败时保留当前作品。

## 本分支未完成部分

### 本地 ASR 连续录音

本地 ASR 当前基于 `MediaRecorder`，需要明确的录音结束时机。没有语音活动检测时，自动截断容易丢失长句，因此本分支只完成浏览器 Web Speech 的免点击连续闭环。后续应以独立 PR 加入端侧 VAD 或流式 ASR。

### 复杂指令拆解

当前一条转写对应一条 `DrawingCommand`。多步骤计划需要新增命令序列协议、步骤状态和部分失败策略，将在独立 PR 中实现。

### 响应延迟优化

当前分支不调整 LLM、生图或角色参考图流程。规则快速路径、生成任务并发和首个可见结果优化将分别评估，避免与语音闭环混在同一 PR。

### 撤销与重试

项目尚未建立通用操作历史，无法可靠支持“撤销”。“重试”也需要区分解析失败、生成失败和部分执行失败，将在状态模型完善后实现。

## 验收脚本

1. 打开页面并批准麦克风权限。
2. 不点击应用界面，说“画一个太阳”。
3. 说“把太阳移到右上角”。
4. 对低置信度指令说“确认”或“取消”。
5. 对两个同名对象说“删除太阳”，再说“右边那个”。
6. 说“保存作品”。
